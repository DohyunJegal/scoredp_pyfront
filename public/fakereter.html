표시되는 정보

점수 패널에는 다음 정보가 표시됩니다:

1. 프로필 카드

  • 쿠프로(クプロ) 이미지
  • DJ NAME, IIDX ID
  • SP 단위 / DP 단위 (段位)
  • ★ 추정값 (실력 지표) — 우측 상단

2. 추천곡 (각 10곡)

해당 단계 아직 못한 곡 중 사용자 ★값 근처 난이도:

  • EASY EC diff 가 ★값 근처
  • HARD HC diff 가 ★값 근처
  • EX-HARD EXH diff 가 ★값 근처

margin = ★값 − 해당 diff 가 −1.0 ~ 2.5 범위. 0.3 정도가 sweet spot 으로 우선 추천.

3. 상세 통계

접힌 상태로 표시되며, 클릭하면 페이지 수/매칭 곡 수/램프 분포를 볼 수 있습니다.

★값 추정 원리

ereter.net 페이지 상단의 단일 ★값 (예: ★10.29) 은 사용자가 임의의 12렙 곡을 클리어할 확률이 50%인 difficulty 지점으로, 실력을 단일 숫자로 나타냅니다.

이 값을 ereter.net 을 참고한 근사치 추정 공식으로 계산합니다:

  • Logistic 모델: P(clear | diff) = sigmoid(α × (S − diff))
  • α = 2.1, S 는 사용자별 maximum likelihood 추정
  • 보정값 +0.77

평균오차 ±0.07, 최대오차 ±0.15 정도의 근사치입니다 (12명 검증 기준).
